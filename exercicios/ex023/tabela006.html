Tabelas em telas pequenas

Em telas pequenas, as tabelas podem se tornar difíceis de ler. Para melhorar a legibilidade, podemos usar CSS para tornar as tabelas responsivas. Uma abordagem comum é transformar as linhas da tabela em blocos verticais, onde cada célula é exibida como um item separado.
